# Experiment 2 – Centralized State Management using Redux Toolkit

## Features
- Redux Toolkit store with posts and platforms slices
- Async thunk to load sample posts after a delay
- Draft and publish flow for social posts
- Platform management and selection

## Run locally
```bash
cd Experiment2
npm install
npm run dev -- --host 0.0.0.0 --port 3000
```

Open http://localhost:3000
